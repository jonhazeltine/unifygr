# Prototypes

Standalone design explorations that are **not** part of the built site. Nothing in
this folder is served — Astro only builds `src/pages/` and `public/`. These are kept
so the work isn't lost, and so a future pass can pick one up and wire it in properly.

| File | What it is |
| --- | --- |
| `vision-landing-prototype.html` | A full-screen, black cinematic landing concept for a **Vision** page, built around the three pillars (Encounter God · Be Transformed · Change the World). Self-contained HTML + CSS + JS; open it directly in a browser. The site's real page today is `/vision-values`. |

To view one, open the file in a browser — no build step, no server.
